# Arquivo histórico

`ci2/` era um pacote na raiz preparado para aplicação sobre outro projeto local. Contém documentação, baselines, scripts, testes auxiliares e workflows de CI/CD.

Ele não é uma segunda aplicação completa. Há referências a arquivos ausentes desta base, como `docker-compose.test.yml`, `executar_regressao.py` e `validar_transporte.py`. Os workflows arquivados não ficam em `.github/workflows` na raiz e não são executados pelo GitHub Actions neste repositório.

Os arquivos foram preservados para consulta, sem integrar automaticamente configurações incompletas ao sistema ativo. Links internos antigos podem apontar para documentos daquela outra base.
