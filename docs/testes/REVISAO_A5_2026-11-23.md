## Decisões do usuário

- **Aprovados:** esquema base v8, propostas 001–008 e banco central do painel Supremo.
- **002:** mantida a **quarentena geral**. Professores de um banco antigo ficam pendentes até
  aprovação administrativa, sem lista de exceções.
- **E-mails com maiúsculas:** tratados na importação de dados reais, se houver. Sem migration
  nova agora; o aplicador já avisa quando encontra esse caso.

**Nada foi executado.** Não existe banco real à espera destas migrations: os ambientes
PostgreSQL atuais nasceram pela base v8. Toda aplicação futura exige backup de banco, uploads e
chave, e o plano do `aplicar_migracoes.py`.
